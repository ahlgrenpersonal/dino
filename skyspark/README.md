# SkySpark

A small, touch-first superhero flying adventure. Fly freely through a sunset city, smash a robot army, slice robots with eye lasers, and unleash an expanding electric sphere. Restore a fountain and rooftop beacon, then dismantle the Iron Colossus. No health loss, flight fuel, timers, or death screen.

The city map reveals three destinations gradually. After the demo, optional robot remixes and a golden sky trail provide free play while the city stays restored. All four powers are available immediately.

Serve this folder with a static HTTP server. Open `index.html` on localhost or HTTPS. Install through Safari's Share → Add to Home Screen on iPhone, or a supported browser's install menu. After the first successful online load and service-worker installation, the game can run offline.

Touch: tap the sky to fly, a rooftop to land, or a robot to smash. Laser aims at the gold-ringed robot. Big Blast expands around the hero. Map destinations handle longer flights. Keyboard: arrows/WASD, L laser, Space blast, M map, Escape pause.

Progress saves locally under a game-specific key. Restart first protects the current adventure as a recoverable backup. Service-worker scope and cache names are isolated from the other games. `refresh.html` refreshes only SkySpark's app shell and preserves saved progress.

All scenery, characters, effects, and music are generated by the app. No reference photographs, external fonts, analytics, accounts, or runtime inference calls are used. The original icon is included locally. All application modules and the service-worker shell use build `world90`.

Run `node tools/verify.mjs` for engine, progression, save, and release checks. Phone browser layout checks do not replace a physical iPhone Home Screen playtest.
